# 玩法指南

[English](../en/gameplay.md) · [返回 README](../../README.md)

PixelWalk 是单人像素漫游游戏。没有积分、战斗或排行榜，行走会带来新风景与日夜交替。公开投稿经维护者审核后成为大家都能看到的社区风景；浏览器里的本地预览不代表已经投稿或上线。

## 操作

| 场景 | 操作 |
| --- | --- |
| 普通行走 | 按住 D / →，松开停止；无需先点画布，在文字输入框中打字不会触发行走 |
| 开局后退 | 按住 A / ←；通过第一个景物后锁定前进，不能再回木屋 |
| 手机普通模式 | 按住画面右侧前进，左侧三分之一后退；松开停止 |
| 沉浸模式 | 点击「沉浸模式」，再按 D / → 开始自动向前；手机点击画面开始 |
| 退出沉浸 | Esc 或双击画面，手机双击；退出立即停止 |
| 暂停 | 失焦、切后台、切路由、打开弹层会停下；返回后重新开始 |
| 重新出发 / 刷新 | 重置本次旅程、后退限制与月相 |
| BGM / ⓘ | 开关音乐、查看来源与调音量；需要用户交互才能播放 |

## 日夜与月亮

每五处风景切换一次日夜，旧景离屏后开始随距离推进的过渡。停止行走时过渡也停止。第一晚为新月，完整走过一晚、黎明过渡结束后才推进一次：新月 → 上弦月（右半亮）→ 满月 → 下弦月（左半亮）→ 新月。刷新或重新出发后重置，不使用真实日期。

## 左侧木屋彩蛋

在通过首景前持续向左走。角色先到开局画面最左边，越过边界才进入独立木屋页；走到门口按 W 或点击提示打开画卷。关闭后仍站在门前，向右返回。画卷作者为 Lin，鸣谢列出已发布社区风景的 GitHub 作者，按账号去重、可搜索并链接主页。

## 创作与投稿

「参与设计」接受透明 PNG / WebP，原图最多 8 MB、1600 万像素，拒绝动图。选择日景/夜景、小/中/大/巨大、地面/空中后自动转换成 160×160 像素 PNG，可在独立试玩中前后移动。试玩、下载和打开投稿表单均不会自动上传图片。

点击「投稿」会下载 PNG 并打开 GitHub 表单；需要 GitHub 登录、手动拖入下载的 PNG、填写素材来源并勾选确认，再提交 Issue。界面现在没有额外的“试玩确认”按钮；生成图片后入口即可用。详见[审核逻辑](moderation.md)和[内容规范](content-policy.md)。

当前创作预览只在页面内存中，刷新会丢失；音量可本地保存。内置配乐为 Scott Buckley 的 Childhood（白天）和 Moonlight（夜晚），默认音量 10%，可调 0–30%，日夜交叉淡化；[完整授权说明](../../assets/audio/LICENSE.md)。
