# 内容规范与禁止内容

[English](../en/content-policy.md) · [README](../../README.md)

PixelWalk 面向希望安静漫游的广泛玩家。规则覆盖图片、作品名、来源说明、链接和评论，也适用于 AI 辅助、像素化、遮挡、谐音、暗号或变形表达。转成像素风不会豁免违规内容。以下是项目收录规则，不是对所有表达作法律判断。

## 不予收录

| 类别 | 禁止范围 |
| --- | --- |
| 色情与性剥削 | 裸露性器官、性行为、色情暗示与招嫖导流；涉及未成年人的性化、剥削或诱导内容一律禁止 |
| 血腥暴力与危险行为 | 血腥伤口、肢解、酷刑、虐待人或动物、暴力威胁、宣扬恐怖主义；鼓励自伤自杀或提供实施指导 |
| 政治敏感与现实动员 | 现实政治宣传、竞选拉票、政党或政治人物宣传、煽动性政治口号、极端主义符号；以领土/主权争议、现实冲突对立等为主题的挑衅内容。无现实动员含义的普通风景或建筑不因所在地区自动被拒，争议情形退回维护者复核 |
| 仇恨、歧视与骚扰 | 因身份攻击群体、去人性化、霸凌、侮辱、跟踪威胁或针对个人的恶意影射 |
| 违法与欺诈 | 非法交易导流、毒品或武器交易、诈骗、赌博推广及教授违法伤害行为 |
| 隐私与权利侵害 | 个人证件、住址、联系方式、私密照片等；未经许可使用受版权、商标或肖像等权利保护的内容，许可不清也应退回 |
| 恶意链接与广告 | 钓鱼、恶意软件、诱导下载、追踪或泄露信息的链接；二维码广告、垃圾投稿、无关商业推广 |
| 不适合漫游展示 | 高刺激闪烁、恶意惊吓、明显破坏安静体验的图片；伪装成系统通知或官方公告 |

## 如何处理

投稿者如有疑问应先询问维护者；不要为了测试审核上传真实违规素材。维护者需人工看图并检查相关文字与链接，不应运行来源不明的附件或程序。未确定来源、许可、表达含义时，使用 `/reject 理由` 请求修改并说明所需信息，避免在回复中再次传播敏感细节。

`/reject` 是退回修改，不是自动封号或删除附件。严重违规可由维护者使用 GitHub 自带的举报、隐藏、锁定或关闭功能处理；管线不自动执行这些动作。涉及隐私/侵权的已发布作品按[下架步骤](publishing.md)移除。删 Git 文件不能清除 Git 历史或 Issue 附件；必要时另行使用平台移除流程。

投稿者可在原 Issue 中说明背景、许可或修订方案，请求另一位维护者复核；申诉不自动重新上线。维护者可基于内容风险、风格适配和来源可靠性不予收录，并尽量说明原因。规则确认只是投稿承诺，不能替代人工审核。
