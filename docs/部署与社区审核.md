当前不需要常驻服务、数据库或自己的图片服务器。浏览器处理创作原图，投稿附件放 GitHub，审核快照与发布图片保存在仓库。当前创作预览只在内存中，不是 localStorage 投稿数据库；音量设置可本地保存。公开 Git 仓库及其历史会随收录持续增长，不能视为无限图片存储。

`npm run build:site` 的 dist 也可以交给普通静态服务器托管。若以后更换域名或存储，应单独确认需求和当时的平台限制；本次未修改服务器、DNS、域名或存储账号。GitHub Pages 自定义域名操作见[官方说明](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/about-custom-domains-and-github-pages)。

Hosting is currently GitHub Pages with workflow builds, HTTPS, and a main-only deployment environment. There is no configured custom domain. Images are processed in the browser, attached to GitHub Issues, and stored as reviewed repository snapshots. No self-hosted server, DNS, domain, or storage account was changed in this audit.
