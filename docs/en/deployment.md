# Hosting and deployment

[简体中文](../zh-CN/deployment.md) · **English** · [Home](../../README.en.md)

PixelWalk is hosted on [GitHub Pages](https://jilinjl.github.io/PixelWalk/), with source in [JilinJL/PixelWalk](https://github.com/JilinJL/PixelWalk). The 2026-10-16 inspection confirmed workflow builds, HTTPS, no custom domain, and a deployment environment restricted to main.

## Where images and data live

Source images are processed in the browser. Contributors manually attach the final PNG to a GitHub Issue. Approval saves a reencoded PNG snapshot under `scenery/images/` and records review/publication state in `scenery/manifest.json`. Publishing generates `content.js` and deploys the static site.

This flow requires no persistent server, database, extra API key, or separate image server. Studio previews exist only in page memory and are lost on reload; volume can be stored locally. The public repository and Git history grow with submissions, so image size needs continued attention.

## Updating the site

- Ordinary main pushes trigger Check and Pages.
- Publication batches explicitly call Pages; bot pushes cannot be relied on to trigger ordinary push workflows.
- Select main when manually running Pages or publishing.
- The `dist/` directory generated by `npm run build:site` can also be served by a normal static host.

See [publishing](publishing.md) for permissions and recovery, and the [audit record](automation-audit.md) for actual evidence. This work did not change a separate server, DNS, domain, or storage account. Future custom-domain setup can follow [GitHub's documentation](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/about-custom-domains-and-github-pages).
