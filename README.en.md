## Leave a little scenery

Turn your idea into a piece of the world. No coding needed: choose an image, preview it in the studio, then follow the [contribution guide](CONTRIBUTING.en.md).

Artwork needs clear provenance, permission for public display and redistribution, and compliance with the [content policy](docs/en/content-policy.md). See [moderation](docs/en/moderation.md) and [publishing](docs/en/publishing.md) for the release process.

## Run locally

Requires Node.js 24+ and Python 3. No npm dependency installation needed.

```sh
npm run dev         # http://127.0.0.1:5173
npm test
npm run build:site  # dist/
npm run build       # outputs/PixelWalk-demo.html
```
